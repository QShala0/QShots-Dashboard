      About the data

      • Read live from the Google Sheet tabs "QShots Engagement" (one row per send, two a day) and "Subscriber Count" (a log taken about weekly). The page reloads the data every few minutes while it is open.
      • Quiz start rate is quiz starts ÷ emails opened. Completion rate is completions ÷ starts. Weeks start on Monday. Rows with no numbers yet are skipped.
      • Day-level subscriber values are estimated on a straight line between logs. Where the log skips more than 5 weeks, the chart leaves a gap instead of guessing.
      • The latest week and month are usually partial and shown faded. Headline figures compare the latest full period with the one before.
